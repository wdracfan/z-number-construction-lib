# Библиотека для построения Z-чисел на основе наборов данных

Данный репозиторий содержит программный код Python-библиотеки для построения Z-чисел на основе наборов данных, разработанной в рамках выполнения выпускной квалификационной работы "Методология построения Z-чисел для представления наборов данных" на образовательной программе "Программная инженерия" факультета компьютерных наук НИУ ВШЭ.

Ниже представлена инструкция по использованию библиотеки. В инструкции даются ссылки на текст исследовательской работы, однако использование библиотеки возможно и без ознакомления с ним.

## Установка

Библиотека может быть установлена с помощью менеджера пакетов `pip` следующим образом:
```
pip install z_number_construction
```
Данную команду следует выполнить в терминале, если планируется локальное использование библиотеки, или же в ячейке в среде Jupyter Notebook в случае её использования. Следует учесть, что в Jupyter Notebook команду, как и всякую sh-команду, следует начать с восклицательного знака:
```
!pip install z_number_construction
```

## Использование

Библиотека предоставляет пользователю два класса:
- `FS` для работы с трапециевидными (в частности, треугольными) нечёткими числами
- `ZNumber` для работы с Z-числами

Логика построения Z-числа на основе набора данных заключена в методе `ZNumber.fit()`. Для его использования следует создать экземпляр класса `ZNumber`, а затем вызвать у него метод `fit()` с обязательным параметром `data` (одномерный массив `numpy.ndarray`) и необязательными параметрами, описанными ниже:
```python
z = ZNumber()
z.fit(data=data, optimize='b')
```
После этого в полях `z.a` и `z.b` будут храниться экземпляры класса `FS`, представляющие A- и B-часть Z-числа соответственно.

Для визуализации можно воспользоваться функциями `plot` и `plot_over_data` класса `ZNumber`.
