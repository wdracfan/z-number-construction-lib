# Библиотека для построения Z-чисел на основе наборов данных

Данный репозиторий содержит программный код Python-библиотеки для построения Z-чисел на основе наборов данных, разработанной в рамках выполнения выпускной квалификационной работы "Методология построения Z-чисел для представления наборов данных" на образовательной программе "Программная инженерия" факультета компьютерных наук НИУ ВШЭ.

Ниже представлена инструкция по использованию библиотеки.

## Использование

Библиотека предоставляет пользователю два класса:
- `FS` для работы с трапециевидными (в частности, треугольными) нечёткими числами
- `ZNumber` для работы с Z-числами

### Построение Z-числа

Логика построения Z-числа на основе набора данных заключена в методе `ZNumber.fit()`. Для его использования следует создать экземпляр класса `ZNumber`, а затем вызвать у него метод `fit()` с обязательным параметром `data` (одномерный массив `numpy.ndarray`) и необязательными параметрами, описанными ниже:

| Название параметра | Тип | Описание | Значение по умолчанию |
|--------------------|-----|----------|-----------------------|
| data | numpy.ndarray | Набор данных для представления в виде Z-числа | - (обязательный параметр) |
| p | float | Регулирует ширину B-части Z-числа | 2 |
| distance | str | Метрика расстояния между функциями: `euclide`, `manhattan` или `chebyshev` | `euclide` |
| u_min | float | Левая граница универсума A-части | min(data) |
| u_max | float | Правая граница универсума A-части | max(data) |
| q | int или str | Количество точек в универсуме, по которым осуществляется перебор возможных A-частей, или `sturges` для вычисления по формуле Стёрджесса |  `sturges` |
| allow_discontinuities | bool | Рассматривать ли такие A-части FS(a,b,c,d), у которых a=b или c=d | False |
| optimize | str | Критерий оптимизации: `specificity` для специфичности A-части, `b` для значения B-части, `both` для их линейной комбинации | `specificity` |
| beta | float | Вес значения B-части при оптимизации `both` | 0.5 |
| c_threshold | float | Порог значения B-части при оптимизации `specificity` | 0.7 |
| s_threshold | float или str | Порог специфичности A-части при оптимизации `b` или `cum` для вычисления на основе сосредоточенности данных | 0.5 |
| defuzzify | str | Метод дефаззификации B-части: `centroid` или `maximum` | `centroid` |

Если в переменную `data` записан исходный набор данных в формате `numpy.ndarray`, то следующий код является примером использования метода `ZNumber.fit` для построения Z-числа:
```python
z = ZNumber()
z.fit(data=data, p=3, optimize='b', s_threshold='cum')
```
После этого в полях `z.a` и `z.b` будут храниться экземпляры класса `FS`, представляющие A- и B-часть Z-числа соответственно.

### Визуализация

Для визуализации результата построения Z-числа можно воспользоваться функциями `plot` и `plot_over_data` класса `ZNumber`, которые строят графики функций принадлежности частей Z-числа на заданных осях. Их сигнатуры таковы:

- `plot(self, axis_a, axis_b, limits_a=None, **kwargs)`
- `plot_over_data(self, axis_a, axis_b, data, limits_a=None, **kwargs)`

Обязательные параметры `axis_a` и `axis_b` суть объекты `matplotlib.axes.Axes`, на которых будет производиться визуализация. Опциональный параметр `limits_a` может быть задан в виде кортежа из двух чисел - границ оси абсцисс на графике функции принадлежности A-части. По умолчанию границы вычисляются автоматически как крайняя левая и крайняя правая точки рисунка. Параметр `**kwargs` содержит дополнительные параметры, которые будут переданы в функции `plot` из библиотеки `matplotlib`. Во второй метод передаётся также обязательный параметр `data` - набор данных типа `numpy.ndarray`, который будет изображён на графике функции принадлежности A-части Z-числа в виде гистограммы, нормированной таким образом, чтобы её максимальное значение было равно 1.

Приведённый ниже код может быть использован для генерации выборки, построения на её основе Z-числа и его визуализации на двух расположенных рядом графиках:
```python
from z_number_construction import *

import numpy as np
import matplotlib.pyplot as plt

_, axes = plt.subplots(1, 2, figsize=(10, 5))
data = np.random.normal(2, 4, size=100)
z = ZNumber()
z.fit(data)
z.plot_over_data(axes[0], axes[1], data, color='red', lw=3)
plt.show()
```
Следует обратить внимание на то, что параметры `axis_a` и `axis_b`, передаваемые в функцию отрисовки графиков, должны быть "подготовлены заранее". За счёт этого обеспечивается гибкость метода: он может быть использован для построения графиков на любых холстах.

### Работа с трапециевидными нечёткими множествами

Для пользователя также может оказаться полезным функционал класса `FS`, который представляет собой интерфейс для работы с трапециевидными нечёткими числами FS(a,b,c,d). Конструктор класса принимает 4 вещественных параметра - a, b, c, d соответственно. Легко видеть, что треугольное нечёткое число может быть представлено как FS(l,c,c,r).

Метод `membership_function()` возвращает функцию принадлежности нечёткого числа (как вещественнозначную Python-функцию от одного вещественного аргумента).

Метод `plot(self, axis, limits=None, **kwargs)` позволяет построить график функции принадлежности нечёткого числа на заданной оси `axis` по аналогии с вышеописанными методами для визуализации Z-чисел.

Метод `specificity(self, u: float)` возвращает специфичность нечёткого множества, вычисленную с использованием универсума, представляющего собой отрезок длины `u`.

Наконец, метод `defuzzify(self, method: str = 'centroid')` вычисляет дефаззифицированное значение нечёткого множества, используя указанный метод дефаззификации - `centroid` для метода центроида или `maximum` для взятия максимума функции принадлежности (для трапециевидного нечёткого множества с ядром ненулевой длины - средний из всех максимумов, то есть середина ядра).
